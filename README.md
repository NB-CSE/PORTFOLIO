## 🌟 Highlights & Features

- **Modern Glassmorphic Dark UI**: Designed with custom CSS variables, subtle ambient glows, and clean typography using Google Fonts (*Space Grotesk* and *DM Sans*).
- **Multi-Page Architecture**: Distinct, dedicated pages for clean organization and easy sharing:
  - `index.html` - Hero overview, live status indicators, stats strip, and featured spotlight.
  - `about.html` - Personal bio, core engineering values, and at-a-glance facts.
  - `skills.html` - Categorized technical toolkit (C++, Python, Web, Core CS, Tools).
  - `education.html` - Academic journey, B.Tech coursework, and self-learning roadmap.
  - `projects.html` - Interactive cards for portfolio, C++ software, Python data tools, and visualizers.
  - `contact.html` - 1-click email copy button with toast notification, social links, and message form.
- **Zero-Dependency Lightweight Core**: 100% vanilla HTML5, CSS3, and JavaScript — no heavy build tools, frameworks, or runtime bloat.
- **Fully Responsive**: Optimized fluid layouts across mobile screens, tablets, laptops, and ultra-wide displays.
- **Fail-Safe Fallbacks**: Automated fallback avatar system to ensure zero broken image displays on any network.

## 🚀 Quick Start / Local Preview

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NB-CSE/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Open directly in browser:**
   Double-click `index.html` or open it with Live Server in VS Code.

---

## 🌐 Deploying to GitHub Pages

1. Push this repository to your GitHub account (`NB-CSE`).
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (or `master`)
   - **Folder**: `/(root)`
4. Click **Save**. Your portfolio will be live in 1-2 minutes!
